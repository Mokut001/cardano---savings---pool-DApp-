# Cardano Savings Pool — DeFi DApp  
A simple decentralized savings smart contract and DApp built on the Cardano blockchain.

## Features
- Plutus V2 validator script (Haskell)
- CIP-30 wallet connection (Nami, Eternl, Lace)
- Simple Servant backend API
- Deployable on Vercel
